# DEEPAM — The Living Rangoli 🪔

A simple, mobile-first Happy Diwali greeting-card studio inspired by traditional Indian rangoli and diya arrangements.

## What visitors can do

- See a prominent **Happy Diwali** greeting with original SVG rangoli artwork
- Tap **Surprise me** to generate a fresh pattern and coordinated colors
- Browse **10 original geometric designs** and **16 curated color stories**
- Keep the greeting artwork visible on a mobile screen while scrolling through options
- Save a high-resolution PNG greeting, or share through supported Android and browser share interfaces
- Tap the card for a subtle celebratory particle effect

The artwork uses radial symmetry, Bézier petals, and gentle animated diya flames. Lamp glow is intentionally low. There are **no** name fields, detailed color-editing controls, glow sliders, paid API calls, sign-in requirements, or watermarks.

## Technology

Single-page HTML, SVG and JavaScript; CSS responsive layout; Canvas 2D celebration particles. Motion is loaded only as an optional progressive enhancement. Offline support is provided by a small service worker.

## Artwork and traditional inspiration

These are original mathematical **interpretations** of traditional rangoli imagery rather than pixel-perfect photographic vectorization. The uploaded reference photographs are not embedded in the hosted site.
